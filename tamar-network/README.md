# רשת תמר – אתר הדגמה

אתר תדמית חדשני לרשת החינוך **תמר – מחוללים שינוי** (עברית / ערבית / אנגלית).

**פתיחה:** פותחים את `index.html` בדפדפן. אין צורך בשרת או בהתקנה.

## מה יש באתר
- דף פתיחה עם מונים מונפשים ומצב "בדרך להכרה כרשת רשמית"
- אודות + ציר זמן 2015 → 2030
- מפת בתי ספר אינטראקטיבית של הנגב (פעילים / בתכנון) עם חיפוש וסינון
- לוח נתונים: KPI, גרף זכאות לבגרות מול ממוצע ארצי, 5 יחידות, יעדי 2030 (עם תצוגת טבלה)
- תכניות לפי שכבת גיל, מודל פדגוגי, סיפורים, חדשות ואירועים
- לוח משרות, טופס הרשמה בשלושה שלבים, תרומות ושותפים
- תפריט נגישות, מצב כהה, עוזר דיגיטלי "תמרי"

## החלפת נתוני הדמה
כל הנתונים נמצאים בראש קטע ה-`<script>` בקובץ `index.html`:
- `DATA`: בתי ספר, מיקומים, מספר תלמידים, נתוני בגרות ויעדים
- `CONTENT`: חדשות, אירועים, משרות, תכניות, סיפורים ושותפים
- `T`: כל הטקסטים בשלוש השפות

> כל הנתונים, השמות, הטלפונים והכתובות באתר הם **נתוני דמה** להמחשה בלבד.

## ניהול ואבטחה
- **מצב עריכה** קיים רק בגרסה שמתארחת ב-claude.ai, ורק לבעלים של האתר (בדיקה של `isOwner` וגם `canEdit`).
  גם לבעלים הוא מוסתר עד שפותחים את הכתובת עם `#admin` או לוחצים Ctrl+Shift+E.
  הפרסום עצמו נאכף בצד השרת של claude.ai: מי שאין לו הרשאת עריכה לא יכול לשמור שינוי, גם אם ינסה לעקוף את הדף.
- **כל התוכן** שנכנס לדף עובר escaping, ותמונות מתקבלות רק כ-`data:image` שנוצרו בדפדפן.

## פרסום רשמי (אתר ציבורי)
`python3 build-public.py` יוצר את התיקייה `public/`: עותק לקריאה בלבד, בלי שום נקודת כניסה לעריכה,
עם Content-Security-Policy מחמיר, קובץ `_headers` (HSTS, X-Frame-Options, nosniff ועוד) ו-`robots.txt`.
את `public/` מעלים לאחסון סטטי עם דומיין משלכם (למשל Cloudflare Pages או Netlify) ומחברים ל-Google Search Console.
