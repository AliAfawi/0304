# חיבור הטפסים לגיליון Google (כ-10 דקות, פעם אחת)

כל הטפסים באתר (הרשמה, מועמדות למשרה, תרומה, פנייה ותיאום סיור) נשמרים בגיליון אחד בחשבון Google שלך,
בלשונית נפרדת לכל סוג, עם עמודת **סטטוס** (חדש / בטיפול / טופל / לא רלוונטי) והתראה בדוא"ל על כל פנייה.

1. פתחו גיליון חדש ב-Google Sheets ותנו לו שם, למשל "רשת תמר – פניות מהאתר".
2. בתפריט: **הרחבות ← Apps Script**. מחקו את מה שיש שם והדביקו את כל התוכן של `Code.gs`.
3. בשורה `const NOTIFY_EMAIL = ''` כתבו את הדוא"ל שלכם בין הגרשיים, ושמרו.
4. בחרו בפונקציה `setup` למעלה ולחצו **הפעלה**. אשרו את ההרשאות (גיליון, Drive לקורות חיים, שליחת דוא"ל).
   ארבע הלשוניות ייווצרו בגיליון.
5. **פריסה ← פריסה חדשה ← סוג: אפליקציית אינטרנט**.
   - הפעלה בתור: **אני**
   - למי יש גישה: **כל אחד**
   לחצו פריסה והעתיקו את הכתובת שמסתיימת ב-`/exec`.
6. באתר: פתחו את מצב העריכה (`#admin`) ← **+ ניהול** ← **הגדרות טפסים ופניות**,
   הדביקו את הכתובת, וגם את הקישור לגיליון עצמו (כדי שיהיה לכם כפתור "פתיחת גיליון הפניות"). פרסמו.

## אבטחה ופרטיות
- הגיליון ותיקיית קורות החיים נשארים פרטיים בחשבון שלכם. הכתובת `/exec` רק מקבלת פניות. היא לא מאפשרת לקרוא אותן.
- כל ערך נשמר כטקסט בלבד, מוגבל באורכו, ובלי אפשרות להזריק נוסחאות לגיליון.
- הגנת ספאם: שדה מלכודת נסתר, זמן מילוי מינימלי, הגבלת קצב (45 שניות לדפדפן, 60 פניות ב-10 דקות לכל האתר).
- קורות חיים: PDF או Word בלבד, עד 4MB, נשמרים בתיקייה פרטית ב-Drive.
- כל טופס כולל אישור מפורש לשמירת הפרטים.
- תרומות: האתר **לא** גובה כסף ולא שואל פרטי אשראי. הוא רושם את הכוונה לתרום. אפשר להוסיף קישור לעמוד תשלום מאובטח של ספק סליקה.

> הטפסים עובדים באתר הרשמי (העותק מ-`build-public.py`). בגרסת העבודה ב-claude.ai הדפדפן חוסם שליחה לאתרים חיצוניים,
> ולכן שם הטופס יציג הודעה שהשליחה לא הצליחה. זו התנהגות צפויה.
