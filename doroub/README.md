# دُروب V8 — نسخة الهاتف أولًا

واجهة جديدة بالكامل لموقع دُروب، مبنية على **نفس بيانات النسخة السابقة دون حذف أي معلومة**،
مع إعادة ترتيب الشاشات والأزرار بحيث يعمل الموقع كتطبيق هاتف لا كصفحة طويلة.

---

## ١ · ما الذي تغيّر

### أقل أزرار
| | النسخة السابقة | V8 |
|---|---|---|
| قوائم التنقل | قائمة علوية + شريط سفلي + روابط التذييل + زرّا الواجهة | شريط سفلي واحد بأربعة تبويبات + أيقونة بحث |
| فلاتر ظاهرة دائمًا | ٦ قوائم منسدلة + ١١ بطاقة تصنيف + ١٠ وسوم سريعة | حقل بحث واحد + ٩ وسوم + زر فلاتر واحد يفتح ورقة سفلية |
| أزرار كل بطاقة | «استكشف» + مقارنة + مفضلة | البطاقة نفسها قابلة للضغط + قلب واحد |
| صفحة المكان | ٥ تبويبات + ~١٢ زر موزّع | صفحة واحدة تُمرَّر، الأقسام الثانوية مطوية، وزرّان ثابتان أسفلها |
| المقارنة | شريط عائم + زر في كل بطاقة | جدول داخل «رحلتي» بلا أي زر إضافي |

**النتيجة: الشاشة الأولى فيها ٦ عناصر قابلة للضغط بدل ٣٠ تقريبًا.**

### صور للمناطق
- الشاشة الأولى صارت مبنية على الصور: ٣ بطاقات للمناطق الكبرى، و١٢ بطاقة للمناطق الطبيعية
  (جبال إيلات، وادي تمناع، النقب، البحر الميت، جبال القدس، السهل والرملة، ساحل الوسط،
  الساحل الجنوبي، ساحل الكرمل، شمال الساحل، الجليل والمرج، بانياس والجولان)، و٨ جولات جاهزة.
- لكل منطقة **مكان مرساة** تؤخذ صورتها من نفس خط أنابيب الصور، فلا تظهر صورة لا تخصّ المنطقة.
- عند غياب صورة موثوقة يظهر بديل لوني يناسب طبيعة المكان (صحراوي/حجري/أخضر) بدل صورة عشوائية.

### مناسب للهاتف
- أربع شاشات حقيقية تتبدّل، لا تمرير إلى مراسٍ داخل صفحة واحدة.
- شريط سفلي يحترم `safe-area-inset`، وأوراق سفلية (bottom sheets) للفلاتر وصفحة المكان.
- صفوف أفقية بـ scroll-snap للمناطق والمختارات.
- الخريطة تملأ الشاشة في تبويبها الخاص.
- خطوط ومكتبة الخرائط **داخل الموقع**: لا طلب إلى أي شبكة توصيل محتوى خارجية.

### كل المعلومات داخل الموقع
صفحة المكان تعرض كل حقل مسجّل في البيانات: الوصف، ما يميّز المكان، ساعات الزيارة وحالتها
وتاريخ آخر مراجعة ورقم الهاتف، تنبيه ما قبل الانطلاق والتحديث الرسمي، الخريطة، شكل المسار
ومحطاته، الرسوم، الحضارة/العصر، طبيعة الزيارة، الاسم الإنجليزي، اسم البحث في تطبيقات الملاحة،
الإحداثيات ومصدر دقّتها، استيراد GPX/GeoJSON ومخطط الارتفاع، تتبّع GPS وتصديره، الطقس،
قائمة التجهيزات، وكل روابط المصادر مع رخصة الصورة.

## ١٫٥ · خمسون ميزة إضافية

أُضيفت ٥٠ ميزة موثّقة في [`FEATURES.md`](FEATURES.md) — من تطبيع البحث العربي
وتجميع دبابيس الخريطة، إلى حاسبة آخر وقت آمن للانطلاق قبل الغروب، والوضع الداكن،
وتصدير الرحلة إلى التقويم. أُضيف زر واحد فقط إلى الواجهة (الإعدادات)؛ الباقي
يعيش داخل أقسام مطوية وورقتَي الفلاتر والإعدادات.

## ٣ · من أين تأتي الصور والإحداثيات

بالترتيب، وأول مصدر ينجح هو الذي يُعرض:

1. **ملف موثّق** مذكور داخل الكتالوج (`photoFile` أو جدول `DOROUB_PHOTO_FILES`).
2. **`data/wiki-cache.js`** — نتائج مجهّزة مسبقًا، تظهر فورًا دون أي استعلام.
3. **ملخّص ويكيبيديا** وقت التصفح (يعطي الصورة والإحداثيات معًا).
4. **بحث ويكيميديا كومنز** مقيّدًا برخص حرّة فقط (CC BY / CC0 / Public Domain).

النتائج تُحفظ في `localStorage` لمدة ٣٠ يومًا، فالزيارة الثانية بلا انتظار.
إن لم يُعثر على صورة موثوقة لا تُعرض صورة بديلة لمكان آخر.

لتحديث الذاكرة المجهّزة بعد تغيير الكتالوج:

```bash
cd doroub
node tools/build-wiki-cache.js      # يمكن إيقافه واستئنافه؛ يحفظ تقدّمه في .wiki-state.json
```

## ٤ · ما لم يتغيّر: قواعد السلامة

- **لا نرسم خط مشي مخمَّنًا.** الخط يظهر فقط من ملف GPX/GeoJSON يستورده الزائر أو من مصدر رسمي.
- **نفرّق بين الدبوس والدائرة.** الدبوس موقع معلم موثّق (وليس نقطة انطلاق)، والدائرة منطقة
  تقريبية واسعة لا تصلح للتوجّه. الإحداثيات المأخوذة من ويكيبيديا تُوسم صراحة بأنها مرجعية.
- **ساعات الزيارة منشورة وليست لحظية**، مع تاريخ آخر مراجعة ودعوة للتأكد هاتفيًا.
- **الطقس** من Open-Meteo وليس تحذير سيول أو إغلاق رسمي.
- ملفات المسار تُقرأ داخل المتصفح ولا تُرسل إلى أي خادم؛ الحدّ ٨ ميغابايت.
- المفضلة والخطة وقوائم التجهيزات تبقى على جهاز الزائر وحده.

## ٥ · التشغيل

موقع ثابت بالكامل، يكفي تقديم مجلد `doroub/`:

```bash
cd doroub && python3 -m http.server 8000
```

- `api/official-track.js` دالة اختيارية (Vercel/Node) لجلب ملفات GPX الرسمية المعتمدة فقط؛
  بدونها يبقى كل شيء يعمل ويستطيع الزائر استيراد الملف بنفسه.
- عامل الخدمة يحتاج HTTPS، ولا يخزّن بلاطات الخرائط ولا صور ويكيميديا احترامًا لتراخيصها.

### ملاحظات على جودة البيانات

- ٢٨ مكانًا من ٧٥ تحمل إحداثيات مكتوبة في الكتالوج؛ الباقي يُستكمل من ويكيبيديا
  ويُوسم بأنه مرجعي. ما يتعذّر استكماله يُعرض كمنطقة تقريبية.
- خمسة عناوين في جدول `DOROUB_WIKI_FALLBACK` لا تقابلها صفحات على ويكيبيديا الإنجليزية
  (تُرجع 404)، فتبقى أماكنها بلا صورة أو إحداثيات حتى تُصحَّح يدويًا.
- المسافات موثّقة لـ٢٣ مكانًا فقط، والبقية تُعرض صراحة كـ«غير موثّقة» بدل تقدير مُختلق.
